# Oche: план работ до запуска на сервере

Два направления, которые идут параллельно:
- **A — сервер и база.** Делаешь ты.
- **B — страница, логика сетки, тесты.** Делает второй разработчик. Базу не трогает.

Делим поровну: примерно 8–10 дней на каждого. Работаем в одном репозитории, каждое изменение — коммит с описанием.
Их связывает **договор API** (этап A0): по нему второй разработчик работает с самого начала на своей заглушке, не дожидаясь готового сервера.
VPS покупаем только в конце (этап A9). До этого всё работает локально.

---

## Стек (предложение)

- Сервер: **Node.js 22 + Fastify** (быстрый и простой) или Express.
- База: **PostgreSQL 16**, миграции через простые SQL-файлы (`db/migrations/001_init.sql` …).
- Логика сетки: **общий модуль `shared/bracket.js`**. Его подключают и страница, и сервер (`resolver`, `feeders`, `gameState`, `placeRange`, `setBracket`, `routeFor`).
- Вход: **VK ID** (OAuth), сессия в httpOnly-cookie.
- Локально: PostgreSQL в Docker (`docker compose up`) или встроенная SQLite для быстрых тестов.
- На VPS: nginx → Node (pm2, 2 процесса) → PostgreSQL. HTTPS через Let's Encrypt.

- текст **политики обработки персональных данных** (имя, город, клуб, VK ID).

## Порядок и точки синхронизации

```
Неделя 1:  A0 (договор, вместе) ──► B0 заглушка, B7 модуль сетки (нужен серверу к A4)
           A1 → A2 → A4                 B1, B2
Неделя 2:  A5, A6, A7                   B3, B4, B5
           ── точка 1: страница подключается к настоящему локальному серверу вместо заглушки
Неделя 3:  A8 исправления               B9 нагрузка, B8 тесты с телефонов, B6
           ── точка 2: полный прогон турнира на 16 игроков локально, 3–4 телефона
           ── покупка VPS → A9 → пилотный турнир
```

**Правила совместной работы**
- Любое изменение API сначала вносится в `docs/api.md`, потом в код. Ломающее изменение — только по договорённости.
- Каждый в своей ветке, слияние через pull request. Второй смотрит изменения, которые касаются договора.
- Логику сетки меняем только в `shared/bracket.js`, с прогоном тестов.
