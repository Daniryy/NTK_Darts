# Трансляция турнира: камеры через VK

Видео вещает VK, Oche показывает его рядом со счётом. Свой видеосервер не нужен.

## 1. Запустить трансляцию

**С телефона (проще всего).** Телефон на штативе — это и есть камера.
1. Приложение VK → сообщество клуба → «Видео» → «Начать трансляцию».
2. Название — например «NDL этап 3 · мишени 1–3». Доступ — «Все» (иначе зрители и табло не увидят видео).
3. Начать. Затем «Поделиться» → «Скопировать ссылку».

**С камер через компьютер (OBS).**
1. VK Видео → «Создать трансляцию» → вкладка с настройками: «URL сервера» и «Ключ потока».
2. OBS → Настройки → Трансляция → Сервис «Настраиваемый», вставьте URL и ключ.
3. Две камеры — две трансляции (два OBS или две сцены с отдельными ключами) либо одна трансляция с двумя камерами в кадре.
4. Битрейт 2500–4000 кбит/с для 720p хватает, интернет на месте — от 10 Мбит/с на отдачу на камеру.

## 2. Добавить камеры в Oche

Турнир → вкладка «Трансляция» → «+ Камера» (до 4):
- **Название** — «Мишени 1–3», «Общий план».
- **Ссылка** — ссылка на трансляцию (`https://vk.com/video-…`, `https://vkvideo.ru/video-…`) или код вставки `<iframe …>` из «Поделиться → Экспортировать». Подходят и YouTube, и RuTube.
- **Мишени** — какие мишени снимает камера: `1, 2, 3`. Пусто — общий план.

«Сохранить камеры».

## 3. Где видно видео

- **Вкладка «Трансляция»** — все камеры.
- **Просмотр матча** — видео камеры, которая снимает мишень этого матча (можно скрыть).
- **Табло для ТВ** — две первые камеры под матчами («Настроить» → «Камеры»).
- **Экран организатора** — каждая камера отдельным окном.

## 4. Задержка

Видео VK отстаёт от реального времени на 5–15 секунд, а счёт приходит почти сразу. Чтобы на табло счёт совпадал с видео: «Настроить» → «Счёт позже на» → 5, 8, 12 или 15 с. Подберите на глаз по 180 или закрытию. Задержка только на этом экране, телефоны маркеров и игроков показывают счёт без задержки.

Если видео не появляется: трансляция должна быть открыта для всех, а у сообщества не должно быть запрета на встраивание видео.
