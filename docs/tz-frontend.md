# ТЗ: страница (делаешь ты)

Базу и сервер делаю я. Запросы к серверу описаны в `docs/api.md`.
Все изменения — в общий репозиторий, в коммите пиши, что сделал.
Пока нужной части сервера нет, страница работает в демо-режиме, как сейчас.

## 1. Модуль сетки — нужен мне первым
- Вынести из `index.html` всю логику сетки в `shared/bracket.js`. Модуль должен работать и в браузере, и на сервере.
- Тесты:
  - 3–64 игроков во всех форматах;
  - каждый игрок получает своё место;
  - пустые места проходят сами.
- Страница выглядит и работает как раньше.

## 2. Подключить страницу к серверу
- Все запросы собрать в одном файле `api.js`, оставить переключатель демо / сервер.
- Экраны берут данные с сервера: лента, турниры, страница турнира, рейтинг, профиль, создание турнира.
- Сетку считает страница через `shared/bracket.js`, с сервера приходят только участники и результаты.
- На каждом экране состояния «загрузка», «ошибка, повторить» и «пусто».

## 3. Счётчик
- Подход сначала сохраняется на телефоне, потом отправляется по порядку `seq`.
- Нет сети — игра идёт дальше, показываем «не отправлено: N», при появлении сети досылаем сами.
- Если матч уже ведёт другой телефон, включаем режим просмотра с кнопкой «Забрать ведение счёта».

## 4. Автообновление и табло
- **Табло для телевизора** (экран организатора): все идущие матчи турнира с живым счётом.
  - Поток `/api/tournaments/:id/stream` через `EventSource` (см. «Табло» в `docs/api.md`); счёт приходит меньше чем через 0,1 с.
  - Анимации 180, перебора и закрытия — по `state.last`.
  - Сетка обновляется по событию `tour`.
- **Открытая страница турнира** тоже слушает поток: сетка обновляется сразу, без перезагрузки.
- **Без потока** (свёрнутая вкладка, старый браузер): опрос `?since=версия` раз в 30 с, на `204` ничего не делаем.
- Свёрнутая вкладка и законченный матч ничего не запрашивают.

Подробности в `docs/api.md` и `docs/server-load.md`.

## 5. Вход через VK
- Кнопка «Войти через VK» и «Выйти».
- Без входа всё можно смотреть.
- «Играть», «Счёт», «Изменить», «Удалить» видят только те, кому можно.

## 6. Проверка и доводка
- **Телефоны:**
  - выключить сеть у маркера и проверить, что всё дошло;
  - открыть один матч с двух телефонов;
  - провести полный турнир на 16 игроков.
- **Нагрузка:** прогнать 250, 1000 и 2000 игроков через API, прислать цифры.
- Понятные ошибки сети, иконка на экран телефона, экран «нет сети».
